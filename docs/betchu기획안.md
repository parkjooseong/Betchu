# BETCHU — 우리 둘의 배팅 몬스터

## 서비스 기획안 v0.1

아래 기획안에서 **확정안**은 지금까지 정한 내용을 그대로 정리한 것이고, **초기 제안**은 게임 밸런스와 실제 개발을 위해 추가한 규칙이다.

BETCHU의 핵심은 서로의 약속에 코인을 걸고, 약속을 지킨 만큼 각자의 몬스터를 성장시키며 아이템과 전투 기록을 쌓는 것이다. 약속 생성부터 베팅, 결과 확인, 뽑기, 장비, 전투까지 하나의 반복 구조로 연결된다.

# 2. 서비스가 해결하는 문제

기존 커플 앱은 사진, 디데이, 일정처럼 **기록 중심**인 경우가 많다. 한동안 사용한 뒤에는 새롭게 할 행동이 부족해질 수 있다.

반면 습관 관리 앱은 목표 달성에는 도움이 되지만, 커플끼리 장난치고 경쟁하거나 함께 성장한다는 느낌이 약하다.

BETCHU는 이 둘을 결합한다.

| 일반적인 행동       | BETCHU에서의 표현 |
| ------------- | ------------ |
| “오늘 1시 전에 잘게” | 퀘스트 생성       |
| 약속에 자신감 보이기   | 코인 걸기        |
| 상대방이 조건 확인    | 퀘스트 승인       |
| 실제로 약속 지키기    | 퀘스트 성공       |
| 보상 받기         | 코인·경험치 획득    |
| 꾸준히 지키기       | 몬스터 레벨업·진화   |
| 번 코인 사용       | 뽑기·아이템 구매    |
| 서로 비교하기       | 전투력·연승·시즌 기록 |
| 함께 노력하기       | 주말 커플 보스전    |

즉, **실제 생활에서의 행동이 게임 속 성장으로 바뀌는 것**이 BETCHU의 가장 중요한 차별점이다.

# 3. 서비스 목표

## 핵심 목표

1. 커플이 하루에 한 번 이상 자연스럽게 상호작용하게 만든다.
2. 사소한 약속도 게임의 퀘스트처럼 즐길 수 있게 만든다.
3. 약속을 지킨 결과가 몬스터와 아이템으로 눈에 보이게 남도록 한다.
4. 경쟁과 협동을 적절히 섞어 한 사람만 계속 지는 구조를 방지한다.
5. 몇 달 동안 사용한 기록이 둘만의 성장 기록이 되게 만든다.

## 하지 않을 것

초기 버전에서는 다음 기능을 넣지 않는다.

* 실제 돈으로 코인 구매
* 코인의 현금 환전
* 다른 커플과 공개 경쟁
* 위치·카카오톡·휴대폰 사용 시간 자동 감시
* AI를 이용한 약속 판정
* 확률형 유료 상품
* 사용자 간 아이템 거래

앱의 느낌도 카지노나 도박보다는 **다마고치·캐주얼 RPG·커플 퀘스트 게임**에 가깝게 만든다.

# 4. 핵심 용어

| 용어     | 의미                              |
| ------ | ------------------------------- |
| 퀘스트    | 커플이 등록한 실제 생활 속 약속              |
| 도전자    | 해당 약속을 수행하는 사람                  |
| 파트너    | 약속 내용과 결과를 확인하는 상대방             |
| 츄코인    | 퀘스트에 걸고 아이템 구매에 사용하는 가상 코인      |
| 배츄     | 각 플레이어가 키우는 몬스터                 |
| 정산     | 약속 성공·실패에 따라 코인과 경험치를 처리하는 과정   |
| 전투력    | 몬스터 능력치와 장착 아이템을 합산한 수치         |
| 케미 게이지 | 두 사람이 퀘스트를 완료할 때 함께 채워지는 협동 게이지 |
| 시즌     | 한 달 단위로 기록을 정리하는 기간             |

앱 내부에서는 `베팅`이라는 표현을 계속 반복하기보다 다음처럼 가볍게 표현하는 것이 좋다.
단, 배츄는 몬스터를 공통적으로 칭하는 호칭이고 각자의 캐릭터 이름은 스타팅 배츄 선택 시 원하는 이름을 입력받아 사용한다.

> “300코인 걸고 도전할래?”
> “오늘은 어떤 퀘스트를 걸어볼까?”
> “결과를 확인해야 배츄가 성장해!”

# 5. 전체 핵심 게임 루프

```text
커플 연결
   ↓
각자 스타팅 배츄 선택
   ↓
퀘스트 만들기
   ↓
코인과 난이도 설정
   ↓
상대방 승인
   ↓
퀘스트 수행
   ↓
성공·실패 정산
   ↓
코인·경험치 획득
   ↓
뽑기·아이템 장착
   ↓
몬스터 성장·진화
   ↓
커플 PvP 또는 주말 보스전
   ↓
더 높은 보상의 퀘스트 도전
```

평일에는 각자의 몬스터를 키우며 경쟁하고, 주말에는 두 몬스터가 힘을 합쳐 보스를 공격한다.

> **경쟁 50% + 협동 50%**

이 비율을 유지해야 한 사람이 계속 뒤처지더라도 게임을 함께 계속할 이유가 생긴다.

# 6. 최초 가입과 온보딩

## 6.1 회원가입

사용자는 간편 로그인을 통해 가입한다.

```text
BETCHU

약속하고, 걸고, 키운다.

[Google로 시작하기]
[Apple로 시작하기]
[카카오로 시작하기]
```

## 6.2 커플 연결

먼저 가입한 사람이 초대 코드를 만든다.

```text
내 커플 코드

B7CHU2

[코드 복사]
[초대 링크 보내기]
```

상대방이 코드를 입력하면 두 계정이 하나의 커플로 연결된다.

## 6.3 스타팅 배츄 선택

커플 연결이 완료되면 각자 알 하나를 받고 스타팅 몬스터를 선택한다. 시작 능력치는 동일하게 두고 외형만 다르게 하는 것이 초기 밸런스에 유리하다. 시작 코인은 각자 1,000코인이다. 

| 스타팅 배츄 | 콘셉트           | MVP 성능 |
| ------ | ------------- | ------ |
| 불 배츄   | 활발하고 장난스러운 외형 | 동일     |
| 물 배츄   | 말랑하고 차분한 외형   | 동일     |
| 풀 배츄   | 포근하고 귀여운 외형   | 동일     |

```text
LV.1
HP 100
ATK 10
장비 0/3
츄코인 1,000C
```

초기에는 능력치 차이를 없애고, 추후에만 전용 스킬이나 진화 형태를 추가한다.

## 6.4 튜토리얼 퀘스트

첫 퀘스트는 시스템이 안내한다.

```text
첫 번째 퀘스트

오늘 자기 전에 물 한 잔 더 마시기

난이도 ★
걸기 100C

[파트너에게 보내기]
```

튜토리얼에서는 실패하더라도 코인을 잃지 않도록 한다.

# 7. 퀘스트 시스템

## 7.1 퀘스트 생성 항목

| 입력 항목    | 예시                |
| -------- | ----------------- |
| 퀘스트 제목   | 오늘 새벽 1시 전에 자기    |
| 카테고리     | 취침                |
| 성공 조건    | 오전 1시 이전에 잠자리에 들기 |
| 난이도      | ★★                |
| 걸 코인     | 300C              |
| 수행 마감    | 오늘 오전 1시          |
| 결과 확인 시간 | 내일 오전 9시          |
| 인증 자료    | 선택 사항             |

## 7.2 퀘스트 카테고리

* 취침
* 운동
* 공부
* 연락
* 게임
* 소비
* 집안일
* 식습관
* 데이트
* 자유 입력

카테고리를 저장해두면 사용자의 과거 성공률과 시즌 통계를 만들 수 있다.

```text
주성이의 게임 퀘스트 성공률
38%

다이노의 취침 퀘스트 성공률
82%
```

## 7.3 퀘스트 종류

### 개인 퀘스트

한 명이 수행하고 상대방이 확인한다.

> 오늘 1시 전에 자기

### 커플 퀘스트

두 사람이 함께 수행한다.

> 이번 주 데이트 사진 5장 남기기

둘 다 성공해야 공동 보상을 받는다.

### 장기 챌린지

며칠간 이어지는 목표다.

> 이번 주 월·수·금 운동하기

### 보스 퀘스트

주간 레이드를 위한 특별 목표다.

> 이번 주 둘이 합쳐 퀘스트 10개 성공하기

MVP에서는 **개인 퀘스트만 먼저 구현**하고 나머지는 후속 버전으로 확장한다.

# 8. 상대방 승인 시스템

퀘스트는 상대방이 승인해야 시작된다. 이는 너무 쉬운 퀘스트로 코인을 반복해서 얻는 문제를 막기 위한 장치다. 기존 기획에서도 상대방이 약속과 난이도를 확인하고 수정 요청할 수 있도록 정했다. 

파트너에게 다음 화면이 전달된다.

```text
주성이가 새로운 퀘스트를 보냈어!

오늘 새벽 1시 전에 자기

난이도       ★★
걸기         300C
성공 조건    오전 1시 이전 취침
결과 확인    내일 오전 9시

[승인하기]
[수정 요청]
[거절하기]
```

## 승인 규칙

| 상황      | 처리              |
| ------- | --------------- |
| 승인 전 취소 | 자유롭게 취소 가능      |
| 파트너 승인  | 코인 잠금 후 퀘스트 시작  |
| 수정 요청   | 도전자가 수정 후 다시 전송 |
| 거절      | 코인 차감 없음        |
| 시작 후 취소 | 두 사람 모두 동의해야 취소 |
| 공동 취소   | 코인 반환, 경험치 없음   |

# 9. 퀘스트 상태

개발할 때는 퀘스트 상태를 명확하게 분리해야 한다.

```text
DRAFT
  ↓
PENDING_APPROVAL
  ↓
ACTIVE
  ↓
AWAITING_RESULT
  ↓
SUCCESS 또는 FAILURE
```

예외 상태는 다음과 같다.

```text
REJECTED
CANCELED
EXPIRED
DISPUTED
```

| 상태               | 의미          |
| ---------------- | ----------- |
| DRAFT            | 작성 중        |
| PENDING_APPROVAL | 파트너 승인 대기   |
| ACTIVE           | 수행 중        |
| AWAITING_RESULT  | 결과 확인 대기    |
| SUCCESS          | 성공 정산 완료    |
| FAILURE          | 실패 정산 완료    |
| DISPUTED         | 두 사람 판단 불일치 |
| EXPIRED          | 결과 응답 없이 만료 |
| CANCELED         | 합의 취소       |

# 10. 결과 확인과 분쟁 처리

## 기본 결과 확인 방식

1. 판정 시간이 되면 도전자가 먼저 성공 또는 실패를 선택한다.
2. 파트너는 도전자의 선택을 보지 않은 상태에서 결과를 선택한다.
3. 두 사람의 응답이 일치하면 자동 정산한다.
4. 일치하지 않으면 `의견 불일치` 상태가 된다.

```text
결과를 확인해줘!

오늘 새벽 1시 전에 자기

실제로 성공했나요?

[성공했어]
[실패했어]
```

## 결과 조합

| 도전자     | 파트너     | 처리            |
| ------- | ------- | ------------- |
| 성공      | 성공      | 성공 정산         |
| 실패      | 실패      | 실패 정산         |
| 성공      | 실패      | 의견 불일치        |
| 실패      | 성공      | 의견 불일치        |
| 도전자 미응답 | 파트너 응답  | 일정 시간 후 자동 실패 |
| 도전자 응답  | 파트너 미응답 | 코인 반환 후 만료    |

도전자가 실패한 뒤 일부러 결과를 입력하지 않는 것을 막기 위해 도전자 미응답은 자동 실패로 처리한다.

파트너가 응답하지 않은 경우에는 도전자가 불이익을 받지 않도록 베팅금을 반환한다.

## 의견 불일치 처리

```text
두 사람의 결과가 달라요.

등록한 성공 조건
“오전 1시 이전에 잠자리에 들기”

[성공으로 합의]
[실패로 합의]
[퀘스트 무효 처리]
```

합의되지 않으면 코인은 반환하고 경험치는 지급하지 않는다.

# 11. 코인 경제 시스템

기본 베팅 방식은 다음과 같다.

300코인을 걸었을 때 성공하면 원금 300코인과 성공 보상 300코인을 받고, 실패하면 걸었던 300코인을 잃는다. 

## 기본 정산

### 성공

```text
퀘스트 걸기       -300C
걸었던 코인 반환   +300C
성공 보상          +300C

최종 손익          +300C
```

```text
잔액 1,000C → 1,300C
```

### 실패

```text
퀘스트 걸기       -300C
반환                0C

최종 손익          -300C
```

```text
잔액 1,000C → 700C
```

## 코인 획득처

| 획득 방법  |           보상 |
| ------ | -----------: |
| 최초 가입  |       1,000C |
| 일일 출석  |         100C |
| 퀘스트 성공 | 걸었던 금액만큼 순이익 |
| 업적 달성  |     100~500C |
| 주말 레이드 |   300~1,000C |
| 시즌 보상  |    등급별 차등 지급 |

## 코인 사용처

| 사용처      |     금액 |
| -------- | -----: |
| 일반 뽑기    |   100C |
| 고급 뽑기    |   500C |
| 전설 뽑기    | 1,000C |
| 장비 강화    |  후속 버전 |
| 몬스터 꾸미기  |  후속 버전 |
| 닉네임 변경권  |  후속 버전 |
| 커플 방 꾸미기 |  후속 버전 |

## 베팅 한도

| 구분        | 선택 가능 금액           |
| --------- | ------------------ |
| 일반,커플 퀘스트    | 100C / 300C / 500C |
| 장기 퀘스트    | 300C / 500C / 1,000C             |
| 보스 퀘스트 해금 | 배팅 없음          |
| 동시 진행 퀘스트 | 최대 5개              |

초기에는 자유 입력을 제공하지 않는다. 고정된 금액만 사용해야 밸런스와 UI를 관리하기 쉽다.

## 코인 파밍 방지 규칙

1. 코인 보상을 받는 퀘스트는 하루 최대 5개다.
2. 상대방이 승인하지 않은 퀘스트는 보상이 없다.

# 12. 코인이 부족할 때

코인이 없어 아무 행동도 할 수 없게 되면 사용자가 이탈할 수 있다. 기존 기획에서는 일일 기본 지급과 긴급 지원금이 제안됐다. 

단순 지원금을 바로 주면 일부러 코인을 모두 사용한 뒤 반복 수령할 수 있으므로, BETCHU에서는 `구조 퀘스트`로 변경하는 것을 추천한다.

```text
츄코인이 부족해!

구조 퀘스트를 완료하면
300C를 받을 수 있어.

“오늘 물 3잔 마시기”

걸기 없음
보상 300C

[구조 퀘스트 시작]
```

## 구조 퀘스트 규칙

* 잔액이 100C 미만일 때만 등장
* 하루 한 번 가능
* 코인을 걸지 않음
* 파트너 확인 필요
* 경험치는 지급하지 않음

# 13. 경험치와 레벨 시스템

코인은 위험과 보상을 결정하고, 경험치는 퀘스트 난이도로 결정한다. 기존 설정은 별 1개부터 5개까지 각각 10, 20, 40, 70, 150 경험치를 제공한다. 

| 난이도   | 기준 예시               | 획득 경험치 |
| ----- | ------------------- | -----: |
| ★     | 간단한 당일 행동           |  10 XP |
| ★★    | 약간의 노력이나 절제가 필요한 행동 |  20 XP |
| ★★★   | 30분 이상 노력해야 하는 목표   |  40 XP |
| ★★★★  | 하루 단위의 어려운 목표       |  70 XP |
| ★★★★★ | 며칠간 이어지는 장기 목표      | 150 XP |

## 난이도 예시

| 퀘스트             | 권장 난이도 |
| --------------- | ------ |
| 물 한 잔 더 마시기     | ★      |
| 오늘 1시 전에 자기     | ★★     |
| 하루 동안 배달 음식 참기  | ★★    |
| 운동 1시간 하기       | ★★★    |
| 공부 3시간 하기       | ★★★★   |
| 일주일 동안 운동 4번 하기 | ★★★★★  |

난이도는 도전자가 선택하지만 파트너가 수정 요청할 수 있다.

## 레벨업 필요 경험치

초기 제안 공식은 다음과 같다.

```text
다음 레벨 필요 XP
= 80 + 20 × (현재 레벨 - 1)
```

예를 들면:

| 현재 레벨 | 다음 레벨 필요 XP |
| ----: | ----------: |
|     1 |          80 |
|     5 |         160 |
|    10 |         260 |
|    20 |         460 |
|    30 |         660 |

MVP 레벨 상한은 `50`으로 둔다.

# 14. 연속 성공 시스템

연속 성공은 경쟁심을 만들지만 한 번의 실패로 지나치게 큰 손해를 주지 않도록 경험치 보너스만 제공한다.

|   연속 성공 | 효과         |
| ------: | ---------- |
|     3연승 | XP +10%    |
|     5연승 | XP +20%    |
| 10연승 이상 | XP +30%    |
|      실패 | 연승 0으로 초기화 |

연출 예시:

```text
🔥 STREAK ×5

5연속 퀘스트 성공!

기본 경험치    +40
연승 보너스     +8
총 경험치      +48
```

칭호도 제공할 수 있다.

```text
3연승  불씨가 붙었츄
5연승  기세 좋츄
10연승 막을 수 없츄
```

# 15. 몬스터 성장과 진화

각 플레이어는 한 마리의 메인 배츄를 키운다.

```text
LV.1  알
  ↓
LV.5  아기 배츄
  ↓
LV.15 성장형 배츄
  ↓
LV.30 최종 진화
```

기존 기획에서도 레벨에 따라 알에서 성장형 몬스터로 진화하고, 실제 약속 기록이 몬스터의 외형 변화로 남도록 설계했다. 

## 기본 능력치 제안

```text
LV.1

HP  100
ATK 10
```

레벨이 오를 때마다:

```text
HP  +8
ATK +2
```

## 전투력 계산

```text
기본 전투력
= HP × 5 + ATK × 20

최종 전투력
= 기본 전투력 + 장착 아이템 전투력
```

예시:

```text
LV.18 배츄

HP 236
ATK 44

기본 전투력
236 × 5 + 44 × 20
= 2,060

장비 전투력
+781

최종 전투력
2,841
```

# 17. 중복 아이템과 강화

불꽃검 획득!

| RARE      |    15조각 |
| EPIC      |    40조각 |
| LEGENDARY |   100조각 |
| MYTHIC    |   250조각 |

```text
불꽃검 +0

필요 재료

[강화하기]

ATK +10
```

아이템 강화는 MVP 이후 기능으로 미루는 것이 좋다. 첫 버전에서는 중복 아이템을 조각으로 저장만 한다.

# 19. PvP 배틀

PvP는 단순 전투력 비교가 아니라 선택형 3턴 전투로 만든다. 기존 기획에서도 공격·방어·스킬 중 하나를 동시에 선택하는 방식이 제안됐다. 

## 기본 규칙

각 턴마다 두 사람이 하나를 고른다.

```text
⚔️ 공격
🛡️ 방어
✨ 스킬
```

상대방이 무엇을 선택했는지 모르는 상태에서 동시에 공개한다.

```text
공격 > 스킬
스킬 > 방어
방어 > 공격
```

## 선택 결과 보정

| 결과    | 피해량 배율 |
| ----- | -----: |
| 상성 승리 |   ×1.3 |
| 같은 선택 |   ×1.0 |
| 상성 패배 |   ×0.7 |

몬스터와 장비의 능력치가 기본 피해량을 결정하지만, 선택을 잘하면 전투력이 낮은 사람도 이길 수 있게 만든다.

## 승리 조건

* 총 3턴 진행
* 3턴 후 남은 HP가 많은 플레이어 승리
* HP가 같으면 총 피해량이 높은 플레이어 승리
* 모두 같으면 무승부

## PvP 보상

PvP에서 큰 코인을 지급하면 강한 사람이 계속 더 강해질 수 있다. 따라서 보상 차이를 작게 둔다.

| 결과  |             보상 |
| --- | -------------: |
| 승리  | 50C + 배틀 메달 3개 |
| 패배  | 20C + 배틀 메달 1개 |
| 무승부 | 30C + 배틀 메달 2개 |

배틀 메달은 능력치 장비보다 프로필 테두리, 승리 포즈, 칭호 등에 사용하는 것이 좋다.

# 20. 주말 커플 보스전

커플 게임이 PvP만 제공하면 한 명이 계속 패배해 흥미를 잃을 수 있다. 그래서 평일에는 경쟁하고 주말에는 함께 보스를 상대하는 구조를 사용한다. 

## 보스전 해금 조건

두 사람의 퀘스트 정산이 완료될 때마다 `케미 게이지`가 1칸 오른다.

```text
이번 주 케미 게이지

████████░░
8 / 10
```

10칸을 채우면 주말 보스가 해금된다.

## 보스 예시

```text
WEEKLY RAID

잠꾸러기 마왕

HP 32,000

주성이 전투력
2,841

다이노 전투력
3,120

커플 합산 전투력
5,961

[레이드 시작]
```

## 전투 방식

두 플레이어가 각자 공격·방어·스킬을 선택한다. 보스도 턴마다 행동한다.

커플이 같은 선택을 하면 합동 효과가 발생한다.

```text
두 사람 모두 스킬 선택!

COUPLE ATTACK

5,960 DAMAGE
```

## 보상

| 보스 난이도 | 보상               |
| ------ | ---------------- |
| 일반     | 300C + 고급 뽑기권    |
| 어려움    | 500C + 고급 뽑기권 2장 |
| 악몽     | 1,000C + 전설 뽑기권  |
| 시즌 보스  | 한정 장비 또는 몬스터 스킨  |

보스전 보상은 두 사람에게 동일하게 지급한다.

# 24. 대표 사용자 시나리오

## 퀘스트 등록

주성이가 퀘스트를 만든다.

```text
오늘 새벽 1시 전에 자기

난이도 ★★
걸기 300C
결과 확인 오전 9시
```

## 파트너 승인

다이노가 조건을 확인한다.

```text
“1시 전에 자기면 별 2개 적당하네.”

[승인하기]
```

주성이의 300C가 잠긴다.

## 퀘스트 성공

다음 날 두 사람 모두 성공을 선택한다.

```text
QUEST CLEAR!

걸었던 코인 반환 +300C
성공 보상       +300C
경험치          +20 XP
연승            3 → 4
케미 게이지      +1
```

잔액은 1,000C에서 1,300C가 된다.

## 뽑기

주성이는 500C 고급 뽑기를 진행한다.

```text
EPIC!

구름 갑옷

HP +70
전투력 +140
```

장비를 장착해 전투력이 상승한다.

```text
2,701 → 2,841
```

## 주말 레이드

그 주에 두 사람이 퀘스트를 10개 정산해 보스전이 열린다.

두 몬스터의 능력치와 아이템을 합쳐 `잠꾸러기 마왕`을 공격한다.

이 한 사이클이 BETCHU의 대표적인 사용자 경험이다.

# 26. 실패 연출 원칙

실패는 게임의 일부지만, 사용자를 비난하면 실제 커플 싸움으로 이어질 수 있다.

따라서 실패 문구는 놀리더라도 공격적이지 않게 만든다.

### 취침 퀘스트 실패

> 배츄에게 다크서클이 생겼어…
> 오늘은 조금 더 일찍 재워주자.

### 운동 퀘스트 실패

> 운동화는 준비됐는데 주인은 나타나지 않았어.

### 게임 종료 퀘스트 실패

> 게임의 유혹이 너무 강했다!
> 다음에는 배츄가 종료 버튼을 지켜볼게.

다음 문구는 피한다.

* “역시 못 지켰네.”
* “신뢰도가 떨어졌습니다.”
* “상대방에게 실망을 줬습니다.”
* “거짓말쟁이입니다.”

몬스터는 약속을 평가하는 심판이 아니라, 실패해도 다시 도전하도록 돕는 캐릭터여야 한다.

# 27. 안전하고 건강한 퀘스트 규칙

기본 템플릿에서는 다음과 같은 퀘스트를 제공하지 않는다.

* 몸무게나 외모를 평가하는 약속
* 식사를 무조건 거르는 약속
* 사생활 공개를 강요하는 약속
* 위치 인증을 강요하는 약속
* 성적인 행동을 조건으로 거는 약속
* 헤어짐이나 질투를 소재로 한 약속
* 상대방에게 돈을 쓰도록 강요하는 약속
* 위험한 행동이나 과도한 운동
* 연락을 강제로 통제하는 약속

커스텀 퀘스트는 반드시 상대방이 거절하거나 수정 요청할 수 있어야 한다.

인증 사진도 필수가 아니라 선택으로 둔다. 인증 자료는 해당 커플만 볼 수 있도록 한다.

# 34. 서비스 성과 지표

BETCHU는 다운로드 수보다 **커플 두 명이 함께 행동하는지**가 중요하다.

| 지표             | 의미                 |
| -------------- | ------------------ |
| 커플 연결 완료율      | 초대받은 상대방이 실제 연결했는가 |
| 첫 퀘스트 생성률      | 연결 후 퀘스트를 만들었는가    |
| 첫 퀘스트 정산률      | 승인뿐 아니라 결과까지 완료했는가 |
| 주간 커플당 완료 퀘스트  | 실제 게임 반복 횟수        |
| 승인 평균 소요 시간    | 파트너가 빠르게 반응하는가     |
| 결과 미응답률        | 정산 과정이 번거롭지 않은가    |
| 의견 불일치율        | 판정 기준이 명확한가        |
| 코인 사용률         | 뽑기가 성장 동기로 작동하는가   |
| 7일 후 재방문 커플 비율 | 반복 재미가 있는가         |
| 레이드 참여율        | 협동 콘텐츠가 작동하는가      |

초기 두 사람 테스트에서는 다음을 확인하면 된다.

```text
일주일 동안
- 각자 퀘스트 5개 이상 완료
- 뽑기 2회 이상 진행
- 결과 확인 누락 20% 이하
- 의견 불일치 10% 이하
- 다음 주에도 새 퀘스트 생성
```

# 35. BETCHU의 핵심 정체성

BETCHU는 단순히 코인을 걸고 성공 여부를 확인하는 앱이 아니다.

처음에는 다음과 같은 사소한 퀘스트로 시작한다.

```text
오늘 운동하기
오늘 1시 전에 자기
답장 미루지 않기
방 정리하기
```

하지만 시간이 지나면 그 행동이 전부 게임 기록으로 바뀐다.

```text
LV.43 배츄
완료한 퀘스트 384개
최고 연승 17회
전설 아이템 7개
커플 레이드 28회
함께 플레이한 기간 137일
```

결국 사용자가 얻게 되는 것은 강한 몬스터 하나가 아니라,

> **우리가 서로 어떤 약속을 했고, 얼마나 지켰으며, 그 과정에서 무엇을 함께 키웠는지 보여주는 둘만의 기록**

이다.

## 최종 서비스 문구

> **BETCHU**
> **우리 둘의 배팅 몬스터**
>
> 약속하고, 걸고, 키운다.
> 평범한 하루가 둘만의 퀘스트가 된다.
